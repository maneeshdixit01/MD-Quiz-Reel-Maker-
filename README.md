# MD Quiz Reel Maker (v11.0 — Bright Cover & High-Contrast Reels Edition)

Instagram Reels, Facebook Reels, YouTube Shorts (9:16) और सामान्य YouTube वीडियो (16:9 लैंडस्केप) बनाने का पूरा वेब व Android (Capacitor) प्रोजेक्ट।

## v11.0 के नए सुधार
- **धुंधला पहला फ्रेम खत्म (Zero Fade-In):** 0 सेकंड पर ही पहला प्रश्न 100% चमक और स्पष्टता के साथ दिखता है, जिससे Instagram का कवर/थंबनेल साफ़ बनता है और Skip Rate घटता है।
- **बड़ा और गहरा हिंदी फॉन्ट:** प्रश्न 64px (900 Bold) और विकल्प 48px (800/900 Bold) तक, साथ में हाई-कॉन्ट्रास्ट थीम रंग।
- **Reels-रेडी डिफ़ॉल्ट:** 5-सेकंड टाइमर और आवाज़ के साथ तुरंत टाइमर शुरू होने की सेटिंग (जिसे आप कभी भी बदल सकते हैं)।
- **v10 के सभी फीचर्स सुरक्षित:** Native Android Hindi TTS, Lossless MP4 Gallery Remuxer (`VideoFixerPlugin.java`), PDF + OCR, 9:16 व 16:9 फॉर्मेट।
