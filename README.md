# MD Quiz Reel Maker (v7.0 — 9:16 Reels/Shorts + 16:9 YouTube Landscape)

Instagram Reels, Facebook Reels, YouTube Shorts (9:16) और सामान्य YouTube वीडियो (16:9 लैंडस्केप) दोनों बनाने के लिए सेल्फ-कंटेन्ड वेब और Android (Capacitor) प्रोजेक्ट।

## v7.0 में नए और सभी फीचर्स
- **दोनों वीडियो फॉर्मेट एक क्लिक में:**
  - **📱 9:16 पोर्ट्रेट (Reels / Shorts):** `1080×1920` (Full HD) और `720×1280` (Fast HD) — ऊपर टाइमर, बीच में प्रश्न, नीचे चारों विकल्प।
  - **📺 16:9 लैंडस्केप (YouTube):** `1920×1080` (Full HD) और `1280×720` (Fast HD) — ऊपर बाईं ओर बड़ा प्रश्न कार्ड, दाईं ओर गोल टाइमर, नीचे 2×2 ग्रिड में चारों विकल्प (`A–B` और `C–D`), और वाइडस्क्रीन अंतिम (Outro) स्लाइड।
- **मैन्युअल + PDF (OCR सहित):** खुद टाइप करें या डिजिटल/स्कैन PDF अपलोड कर एक-टैप में सही उत्तर मार्क करें।
- **वॉइस रिकॉर्डिंग + ऑटो हिंदी आवाज़ (TTS):** हर प्रश्न पर वैकल्पिक माइक रिकॉर्डिंग/ऑडियो अपलोड (IndexedDB में सेव व सीधे MP4 में मिक्स) और ऑटो हिंदी TTS।
- **अंतिम संदेश (Outro) + फुल-स्क्रीन प्ले + Android APK रेडी।**
